# Ideas

IntentArc saves ideas without changing current work. Open **Capture idea** from
an active project, enter the thought, and choose **Save idea**. The first line
becomes the inbox title; the complete text remains in the authoritative record.

## Context and authority

Captured ideas are provisional human records. Available task or component
context is linked explicitly. Capture does not change task status, project
priority, roadmap membership, repository files, Git, or repository refresh.

## Read-only inbox and detail

**Ideas** lists newest captures in bounded pages. Open an idea to inspect its
complete plain-text body, current status, provenance, revision, timestamps, and
linked task/component context. Context links open the existing Project Map
focused on that record.

Ideas still cannot be edited, deleted, scheduled, promoted, evaluated, or sent
to AI for automatic analysis. Opening detail does not change current work,
repository files, Git, or repository refresh.

## Recovery

Validation, revision, context, or network errors keep the draft. Refresh the
project context and retry explicitly. After an ambiguous network or service
failure, retrying an unchanged submission is safe and never silently creates a
second idea. Repository refresh remains a manual, read-only action; idea capture
does not start or change it.
