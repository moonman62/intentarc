# Product scope

IntentArc provides a local archive for project knowledge, governed changes,
task coordination, repository onboarding, project exploration, and reviewed
context handoff. The browser interface, CLI, and MCP server use the same
application services.

AI clients receive only the access granted to their local profiles. Context
release, repository refresh, and authoritative changes follow the separate
review boundaries described in the user guides. There is no hosted team
sync or automatic AI-provider execution.

This is an early source release. Functional coverage does not establish
signed-installer or cross-platform readiness. See
[release status](release-readiness.md) for the current limitations and the
[README](../README.md) for setup.
